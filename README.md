# GitHub Workflow Practice

This repository is used to practise the standard GitHub team workflow:
working with issues, branches and pull requests.

## Workflow

1. **Issue** – describe the task or problem in the Issues tab.
2. **Branch** – create a separate branch for the task (for example `docs/update-readme`).
3. **Commit** – make the changes in that branch.
4. **Pull Request** – open a PR into `main` and link it to the issue with `Closes #<issue number>`.
5. **Review & Merge** – after review, the PR is merged and the linked issue is closed automatically.

## How to contribute

1. Pick or create an issue.
2. Create a branch from `main`.
3. Commit your changes with a clear message.
4. Open a pull request that references the issue.
